Lab/Editor HTML/CSS

Editor HTML/CSS dal vivo

Scrivi HTML e CSS a sinistra e guarda la pagina prendere forma a destra, in tempo reale. Cambia un colore, un testo, un margine: il risultato si aggiorna mentre scrivi. La palestra perfetta per chi inizia a fare web.

L'anteprima gira isolata: solo HTML e CSS, nessuno script.
HTMLla struttura della pagina
CSSlo stile e i colori
la-mia-pagina.html

Suggerimento: il tag <style> è già pronto per te — scrivi le regole CSS direttamente nel riquadro CSS.
